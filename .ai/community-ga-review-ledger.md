## Method

For each open PR head and each non-ancestor `ai/grok/*`, `ai/codex/*`, non-bot, and cursor ref:

1. `git merge-base --is-ancestor <tip> HEAD`. True means **already contained** (behavior retained; the tip commit is reachable).
2. Otherwise `git cherry HEAD <tip>`. Zero `+` lines means **patch-equivalent already contained** (behavior retained under different SHAs).
3. If `+` lines remain, `git merge-tree --write-tree HEAD <tip>`. A clean result equal to `HEAD^{tree}` is also **patch-equivalent already contained** (the tip adds no tree change).
4. Otherwise the unique patch was reviewed against HEAD: same tests or same-subject integration commits => **superseded** (behavior reworked); intentional omission => **held**; not proven => **unknown**. Nothing in the open PR set was left as a product **needs port**.
5. Local branch tips that differ from `origin/<name>` were classified separately. A contained origin tip does not hide a diverged local tip.

Ancestor refs are counted and not re-listed. They are already contained.
