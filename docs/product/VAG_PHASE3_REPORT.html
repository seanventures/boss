What it means for offerings

The VAG thesis held: put the frontier on the gate, not the keyboard.

Hybrid (DeepSeek implements, Claude verifies) hit the same 80% pass-rate as full-Claude, at ~25% lower $/verified. The implementer can be cheap and fast if the verifier is strong.

The verifier is the binding constraint — and gpt-4o is a weak one.

Full-Azure scored 0/5: gpt-4o wrote tests it then couldn't pass and broke regression, even after 3 repairs, and its own review couldn't save it. Azure-as-gate hybrid reached only 40%. Claude-as-gate is what makes hybrid work. Azure is fine as a cheap implementer, not as the judge.

The repair loop recovers slips, not capability walls.

It earned a pass on slugify (DeepSeek failed first try → 1 retry → passed) but couldn't save md_toc, where DeepSeek produced no working implementation across all 3 retries. Net pass-rate was flat here only because n=1 is noisy.

Zero false passes across all 25 runs.

The fail-closed gate never approved bad work — including gpt-4o's 25 failed attempts. The integrity invariant that makes the whole strategy trustworthy held.
