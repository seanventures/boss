What the numbers say

  • Panel-3 costs 0.78× panel-1 per verified outcome ($4.9252 vs $6.2997) — the review stage runs 3 critics instead of 1.
  • Wall-clock is nearly flat: panel-3 mean 2040s vs panel-1 1538s (+33%) — the extra reviewers run in parallel, so the panel is a cost multiplier, not a latency multiplier.
  • Clean-task pass-rate: panel-1 60% vs panel-3 80% — no false-fails introduced.
  • Known-bad probes caught: panel-1 0/1, panel-3 1/1 (a false-pass = the verifier was fooled).
  • Mean panel confidence: panel-1 0.83 (single vote → always 0 or 1), panel-3 0.93 (a real distribution — the new signal).

Honest caveats

  • The clean tasks are high-pass, so panel size mostly moves cost and the confidence distribution, not clean-task pass-rate. The panel's marginal catch is best isolated by a verifier meta-eval (labeled bugged/clean diffs fed to the panel directly — queued as #105).
  • Known-bad probes here are planted contradictions caught by the whole gate (often at the test stage), so they measure gate trustworthiness, not the panel alone.
  • Claude runs on the Max plan (≈$0 marginal); $/verified bills it at API list price for honest accounting, so out-of-pocket is far lower than shown.
