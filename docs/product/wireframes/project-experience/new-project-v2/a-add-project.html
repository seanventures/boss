Design notes — one screen, one button
  1. 1 One input. A sentence → new app; owner/repo, a GitHub URL → existing repo; /path → folder on a host. The kind pill shows the guess and can be clicked to force another. Replaces the New / Existing tabs and the 3-column picker.
  2. 2 The summary is a diagram of six boxes (captain → stack → connectors → workflow → code → staging). Every value is pre-picked; a box opens its popover in place (screen b). Nothing is asked up front.
  3. 3 Repo mode: search runs inline as you type (GitHub repos and host folders in one list, in use tag kept). Helm starts reading the highlighted repo live, so the summary fills with what was found.
  4. 4 Models and the GitHub account are global: shown read-only (readiness dots, account chip); + account opens Repo and models. Never picked here.
  5. 5 One primary, Create and start (⌘↵). Try a sample starts in one press. Plan-with-an-agent, blank and knowledge-graph projects and presets stay one press away under the footer links.
