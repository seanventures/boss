Design notes
  1. 1 The inline composer leaves the Work tab; one bar opens the modal. Keyboard users keep a zero-click path (type, ⌘↵).
  2. 2 The kind picks the workflow and what Helm asks. Nothing is asked up front: every value is pre-picked.
  3. 3 “change” is the Workflow chip’s popover. The Quick/Small/Spec/Major sizes from the old New build map onto these workflows.
  4. 4 From the Work tab, a mouse start costs one more click (2 instead of 1), so the brief is seen before work starts. From the header, the count is unchanged.
  5. 5 Every row of today’s composer is kept; the source is apps/web/app/projects/tab-work.tsx › Composer.
