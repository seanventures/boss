# Getting started

Use the [quickstart](QUICKSTART.md) for the path: install v1.0-rc10.11, [claim the install](QUICKSTART.md#claim-the-install), connect one repository, connect one model, and open one pull request.

To inspect a run's state or evidence after that, use the [first change](FIRST_USEFUL_CHANGE.md). HTTPS on a hostname you control is [separate](hostname.md). Sign-in details are in [sign in](CONSOLE_AUTH.md).

This page used to be a recorded install transcript, including local-model timings. Those timings are not a current performance guarantee, and they are not repeated here.

## The governed path

Read the plan before you treat the run as started. The default path's web research step needs a usable Claude Code subscription. Without one, that step is recorded as skipped and the run continues. The sequence and the checks are in the [first change](FIRST_USEFUL_CHANGE.md).
