## Remaining release checks

The complete web suite, final production images and source census, integrated installer lifecycle, worker/identity boundaries and browser path are in progress. The first full web run after the dependency change retained two image-fixture failures; the narrowly corrected fixtures passed all six actual PNG cases, and the final whole-suite repeat remains pending. The navigation correction has production and semantic proof, but the visible-response target stays open until a browser with a nonzero viewport is available. Reusable acceptance checks and agent voice intents have independent source qualification; conversation streaming and its request-spend authority are receiving separate correction.

Before inviting testers, verify a genuinely useful bounded result with an ordinary configured provider, external-effect and older-snapshot reconciliation, supported clean-host installation, uncoached human first use, and the hosted installer/manual contract. A harmless installed worker job or an agent-authored review does not establish those outcomes.

RC9 publication, hosted deployment, invitations and human usefulness acceptance are distinct milestones. The eventual tag identifies the published source; downloaded release assets need their own exact-commit and checksum verification.
