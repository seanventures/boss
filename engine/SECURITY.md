# BOSS Engine Security Policy

## Supported versions

Before the first public release, supported versions will be listed here and
the release owner will define the security-fix maintenance window.

## Reporting a vulnerability

**Do not open a public issue for a suspected vulnerability.** Email
**boss@sean.net** with redacted reproduction evidence. Design partners may also
use the private escalation contact supplied with their access.

When reporting, include:

- affected engine version or commit;
- affected component and impact;
- minimal, safe reproduction steps;
- mitigations already attempted; and
- whether credentials, tenant boundaries, approvals, receipts, budgets, or
  provider actions are involved.

Do not send secrets, customer data, active credentials, or production access
details in an issue or unencrypted message.

## Response expectations

The release owner will acknowledge a valid report, assess severity and scope,
coordinate remediation, and publish an appropriate advisory after affected
users can act. Exact response targets remain a release decision.
